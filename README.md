# HM Hostel Management System

A modern and responsive **Hostel Management System** frontend built with React and Tailwind CSS.

## 📌 About the Project

**HM Hostel Management System** is a web-based frontend application designed to simplify hostel management and provide students with an easy-to-use portal for accessing their hostel information.

The system has two main interfaces:

* **Admin / Hostel Manager Dashboard**
* **Student Portal**

The current version is **frontend-only** and uses local mock data for demonstration purposes. Backend, database integration, and real authentication will be added in a future development phase.

## ✨ Features

### Admin Dashboard

* Dashboard overview
* Student management
* Add, edit, view and delete students
* Room management
* Add, edit, view and delete rooms
* Room allocation management
* Add, edit, view and delete allocations
* Payment management
* Expense management
* Reports
* Notifications
* Settings
* Responsive admin navigation
* Mobile-friendly sidebar

### Student Portal

* Student dashboard
* Student profile
* Personal information
* Academic information
* Hostel and room information
* My Room
* Payments
* Requests
* Responsive student navigation

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/JOSEPH627/hostel-management-system.git
```

### 2. Open the project

```bash
cd hostel-management-system
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal.

## 📱 Responsive Design

The application is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

On smaller screens, navigation changes to a mobile-friendly hamburger menu and sidebar.
